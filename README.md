## Project Overview
End-to-end machine learning pipeline for predicting consumer
financial distress using the Give Me Some Credit dataset.

## Dataset
Give Me Some Credit — Kaggle
https://www.kaggle.com/competitions/GiveMeSomeCredit

## Models Implemented
- Logistic Regression (baseline)
- Random Forest
- XGBoost (primary model, tuned via RandomizedSearchCV)

## Best Result
XGBoost (Tuned) AUC-ROC: 0.8696

## How to Run
Open the .ipynb file in Google Colab.
Run all cells sequentially from top to bottom.
All dependencies are installed in Cell 1.
